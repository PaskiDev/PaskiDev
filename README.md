## What I work on

**Data**

- **[arkeion](https://arkeion.tech)** — versioned, audited database engine in Rust. Every write is a signed commit. Open source.
- **[inro](https://inro.syrakon.com)** — dense multi-tenant runtime. Thousands of isolated databases per box. Open source.

**Version control**

- **[torii](https://torii.sh)** — change-centric version control, built for working with AI agents.
- **[gitorii](https://gitorii.com)** — the `torii` CLI over plain git repos. Browse a remote without cloning. Open source.

**Platform**

- **[svitrio](https://svitrio.com)** — headless CMS and business platform. Runs every site listed here.
- **[quota](https://quota.at)** — usage metering and billing for EU teams.
- **[galeon](https://github.com/PaskiDev/galeon)** — container CLI for the whole lifecycle: scaffold, run and ship images for any stack. Open source.

**Browser**

- **[rumb](https://rumb.net)** — experimental Rust web browser. Servo for the content, Zed's GPUI for the chrome. Pre-alpha. Its Servo fork, [tramuntana](https://gitlab.com/syrakon/tramuntana), is open source (MPL-2.0); the browser shell is proprietary.

Plus the plumbing nobody sees: a compression codec line, a mail relay, provisioning scripts, and a self-hosted edge that serves all of the above from one machine.
